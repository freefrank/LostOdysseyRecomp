# Debug menu 需求

## 当前战斗判胜（2026-09-04）

已实现 Windows F1 菜单和一次性判胜请求，用户实测确认可以跳过战斗。请求由客体线程在命令阶段或动作边界执行，调用阶段 11 和结果初始化；阶段 12 是失败，不能误用。菜单不暂停游戏。

判胜作为快速推进剧情的优先实现，攻击力调整保留为后续需求。尚未验证全部特殊战斗、奖励和存档。

## 主角攻击力调节（2026-09-04）

状态：待实现。用户提出用于快速通过战斗、推进剧情和渲染验证。

- 游戏运行中可通过快捷键打开/关闭 debug menu，显示调试启用状态。
- 显示主角当前攻击力，支持临时设置攻击力及攻击力倍率。
- 提供恢复默认值的操作；关闭修改后恢复正常计算路径。
- 仅影响主角，不改变敌方数值，不写入存档或游戏资产。
- 默认关闭；重新启动后恢复正常状态。
- 暂停、目标选择、战斗切换及角色数据重建后，设置应有明确且一致的作用范围。

实现前需定位客体攻击力/伤害计算入口，并区分基础攻击力、装备与状态加成。
验证应覆盖：普通攻击伤害确实变化、敌方攻击不变、恢复默认后行为恢复，以及剧情推进正常。
不能只修改 UI 显示值，或用全局伤害修改代替主角攻击力修改。
