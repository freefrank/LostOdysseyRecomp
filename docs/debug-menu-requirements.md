## 地图信息与待实现需求

地图数字 ID、本地化名称和内部包名已实现。标题显示未知状态；Hypocenter、Gorge 与 Hypocenter→Edge of Wasteland 切图更新已实测。未识别/多地图歧义时不沿用旧名称；游戏线程超过两秒未更新时 UI 显示未知。见[地图信息](notes/debug-map-info.md)。
- 随时存档开关：默认关闭，复用正常保存流程，必须验证保存和独立重启读回。`CheckSavePoint`带交互副作用，不能直接当bool强制开启。

## 当前战斗判胜（2026-09-04）

已实现 Windows F1 菜单和一次性判胜请求，用户实测确认可以跳过战斗。请求由客体线程在命令阶段或动作边界执行，调用阶段 11 和结果初始化；阶段 12 是失败，不能误用。菜单不暂停游戏。

开场编号 0–2 的直接判胜现在补齐凯姆持久资源 11→0，避免将缺少普通攻击动作的开场专用资源带到后续遇敌；战斗 0x139 兼容恢复旧状态。具体证据见 [遇敌调查](notes/encounter-animation.md)。这不代表所有特殊战斗的脚本收尾都已验证。

判胜作为快速推进剧情的优先实现，攻击力调整保留为后续需求。尚未验证全部特殊战斗、奖励和存档。

## 主角攻击力调节（2026-09-04）

状态：待实现。用户提出用于快速通过战斗、推进剧情和渲染验证。

- 游戏运行中可通过快捷键打开/关闭 debug menu，显示调试启用状态。
- 显示主角当前攻击力，支持临时设置攻击力及攻击力倍率。
- 提供恢复默认值的操作；关闭修改后恢复正常计算路径。
- 仅影响主角，不改变敌方数值，不写入存档或游戏资产。
- 默认关闭；重新启动后恢复正常状态。
- 暂停、目标选择、战斗切换及角色数据重建后，设置应有明确且一致的作用范围。

实现前需定位客体攻击力/伤害计算入口，并区分基础攻击力、装备与状态加成。
验证应覆盖：普通攻击伤害确实变化、敌方攻击不变、恢复默认后行为恢复，以及剧情推进正常。
不能只修改 UI 显示值，或用全局伤害修改代替主角攻击力修改。

## 同地图人物传送（2026-09-04）

已实现并通过后台同地图往返与移动验证，见 [传送说明](notes/debug-teleport.md)：显示玩家世界坐标，填写XYZ传送，保存/返回当前地图记录位置，XYZ各±100微调。菜单线程只提交请求，客体游戏线程调用原生位置更新；记录随切图失效，战斗期间不可用。不提供跨地图加载；到达目标位置仍可能触发游戏事件。记录在切图、打开游戏菜单或失去角色控制时失效。

POI扩展：F1传送区读取当前已加载地图的存档、入口/出口、机关、拾取/触碰点，支持选点传送及坐标/距离预览。后台执行时复核Actor身份和Level成员关系，切图/禁控会清列表。实现/验证见[传送记录](notes/debug-teleport.md)。不提供尚未加载地图的跨图传送。
