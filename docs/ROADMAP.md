## PC graphics direction

D3D12 remains the working baseline. Windows Vulkan has bounded RTX 5080 scene validation and remains separate from wider GPU and full-game coverage. Direct3D 11, Linux/Steam Deck and Switch are independent platform work; no completion or release date is implied. The Linux first-playable scope is implemented as a Vulkan-only unbundled ELF launched with `./LostOdysseyRecomp --game <disc>` on host Mesa + SDL2 + X11/XWayland. A WSL2 Manjaro + Mesa Dozen run reached a 1280x720 Vulkan window and exited 0 after the user closed it; native Linux ICD, Steam Deck, and broader game-flow coverage remain open. Linux installer/importer, XDG/Flatpak user path routing, POSIX libcurl updater, and Flatpak manifest are implemented; Linux AppImage packaging (`tools/package_appimage.py`) is published with the [v0.5.20 release](https://github.com/freefrank/LostOdysseyRecomp/releases/tag/v0.5.20), bundling the portable Vulkan shader pack (`shaders/portable_vk.lospv`). The menu branch replaced Win32 dialogs with a cross-platform software rasterizer and in-game debug overlay. Fast on-demand Linux builds (`tools/build_linux.sh` / `tools/build_wsl.bat`) and cross-platform portable Vulkan shader packs (`.lospv`, verified 1.2s zero-compile startup on WSL2 Linux with 28,482 shaders) are implemented. Native Steam Deck sniper runtime packaging, Flathub publication, and full playthrough validation remain open. See the [Linux port evaluation](notes/linux-port-evaluation-2026-09-13.md).
