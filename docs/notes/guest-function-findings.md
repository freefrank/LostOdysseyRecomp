# Guest function findings ledger

Address-level findings about the retail guest code (disc 1 `default.xex`) collected from issue investigations, runtime hooks and research notes up to 2026-10-09. Newer notes on `main` are not on this branch, so each finding is kept here as one row with its source. Labels are search labels, not recovered symbols, and no row is proof of runtime behaviour.

- **Kind**: `func` function entry; `insn` instruction inside a function (hook point, call site, return address); `global` guest global or object pointer; `data` static data; `vtable` virtual table.
- **Confidence**: `documented` means the source states it as a finding or a merged hook or fix relies on it; `historical_candidate` means the source hedges, the finding comes from one unverified report, or its purpose is unknown.
- **Source**: `path:line` refers to `origin/main` at `7d3c66a6` (2026-10-09) unless noted. `memory <file>` is a maintainer Claude Code file memory; `BM "<title>"` is a Basic Memory note in `projects/lost-odyssey-recomp/`; `_keep/...` is a maintainer-local research folder outside the repository. `#N` is an issue or pull request of freefrank/LostOdysseyRecomp.
- Function entries also have an entry in [annotations.json](../../tools/ghidra/annotations.json) whose evidence cites the row line below. Other kinds are indexed by `analysis_catalog.py` as document mentions only.
