# 逆向笔记

每个子系统一个文件，记录：地址范围、已命名函数、恢复的结构体、未解之谜、验证方法。
新会话开始前先读相关笔记。

建议文件：
- `xex.md`         XEX 版本、导入表、节区布局
- `kernel.md`      游戏用到的内核函数清单及实现状态
- `renderer.md`    渲染管线、RT 布局、EDRAM 用法、着色器分类
- `audio.md`       XMA 流、音效系统
- `filesystem.md`  读盘路径、四张盘的数据分布
- `ue3.md`         UE3 反射表、UObject 布局、UnrealScript 字节码入口
- `battle.md`      feelplus 自研战斗系统
- `patches.md`     已打的补丁及原因
