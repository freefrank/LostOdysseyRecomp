# v0.8.0 游戏 DLSS FG 接入记录

日期：2026-09-27。范围：Windows Vulkan 下的实验性原生 DLSS SR + Streamline DLSS FG 游戏路径。

## 已落地的路径

在 `LO_ENABLE_STREAMLINE_FG=ON` 且找到 pinned Streamline SDK 时，游戏构建会编译 Streamline runtime、Vulkan dispatch、DLSS FG 输入常量与深度转换，以及 renderer/video 的提交和最终 backbuffer handoff。运行时使用 `LO_DLSS_FG=1` opt-in；默认仍关闭。当前目标是 Windows Vulkan native DLSS SR 路径，FSR provider、D3D12 和其他平台不在本次接入范围。

renderer 现在准备真实场景的 color/depth/motion 输入，并将深度转换到匹配有限投影的输入约定。present 路径使用 `eBlockPresentingClientQueue`，在 post-present marker 上检查完成 fence，并通过窗口 handshake 管理生命周期。最终 backbuffer 仍包含 UI；HUDless/UI 分离保持 `Unavailable`，没有启用 screen subtraction 或 shader/ordinal 白名单。

本轮性能修复将运行时 snapshot 从五张纹理缩减为 depth+motion 两张；五图仍保留在诊断快照路径。DepthRemapper 的 output、常量缓冲、descriptor 和 framebuffer 在 checked SDK input drain 后复用。renderer 只在真实 final-resolve batch 成功提交到同一 queue 后写入 serial，`ReadyForOrderedSubmission` 依赖 present semaphore 的 GPU 顺序，移除 `Acquire` 的 CPU `WaitForGpu`；原有 Ready 状态仍要求真实 CPU fence 完成。Session 在 checked SDK 完成前保留 strong leases，并增加分段 CPU 计时。

此前的 SDK trace、official sample 复现和 P0 probe 结果仍是历史诊断证据；它们不再表示游戏接入尚未开始，也不表示 SDK 或 Gate 1 已验收。SDK hazard、validation 和 physical-display 限制仍需在真实游戏路径中重新观察。

## 实机运行工具

`tools/perf/run-fg-game.ps1` 提供有界的前台、静音诊断：它复制 isolated settings/save/profile/shaders，清理并设置 `LO_DLSS_FG`、`LO_AUDIO_MUTE=1` 和独立 shader cache，自动执行 Uhra 路线、运动输入并只关闭自己启动的进程。需要显式提供 build、baseline、output 和 game 目录；`-DisableFg` 可生成相同路线的 FG-off 基线。脚本会保存 executable hash、stdout/stderr、runtime log、终止状态和存档/profile 元数据保护结果，不覆盖既有输出目录。

该工具已用于限定真实游戏验证，但仍不能把启动成功或退出码 0 单独当作生成帧显示、物理显示或完整画质验收。`-DisableFg` 生成的是相同路线 FG-off 基线，而 FG 开关也改变 VSync/DPI 策略。UI 分离仍暂停，production provider readiness、跨场景覆盖及用户验收继续待定。

在 `out/fg-game-20260926/host-pacing-comparison.json` 的 2200–2800 帧窗口中，FG-on（run05）601 个有效 host-present 间隔的 mean/median/p95/max 为 `19.25365/18.8444/22.786/45.2049 ms`，host rate `51.94/s`；FG-off（run06）为 `16.78145/16.6909/17.2575/24.7995 ms`，host rate `59.59/s`。该对照包含 FG 输入复制、深度和同步额外开销，且 FG 改变了 VSync/DPI 策略，因此不是纯单变量性能测试，不能推导 physical display FPS 或最终净收益。run06 正常退出（exit 0、`forced_stop=false`、`baseline_preserved=true`），FG 未初始化。
