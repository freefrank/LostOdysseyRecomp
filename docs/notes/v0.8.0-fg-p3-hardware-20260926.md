run02 的 trace 已确认：draw `2145`（line 100959）是 scene-copy，shader 为 VS `8bbd4da701845d16`、PS `cda578aef1724fdc`，fetch line 100988 读取地址 `0xb0d9000`、`1707x960`，counter `47148`，raster extent `2560x1440`。draw `2146`（line 100989）是首个后续 overlay candidate，使用 VS `eb5f611c4321708e`、PS `38b953b91dcfd9ce`；其 blend 与 1x1 texture 记录不足以证明全屏覆盖，随后 draw `2147` 才切换到 minimap scissor `(972,40)-(1192,205)`。2146–2166 共 21 个后续 overlay，draw 2167 为 resolve 命令，最终 resolve 为 draw 2168，地址 `0x714000`、`2560x1440`、ordinal `47149`（lines 101352–101353）。因此 `writable_transition` 确认发生在 scene-copy 后首个后续 overlay candidate，属于 snapshot lineage 失效；它不是 snapshot submit failure。UI 分离仍是下一步，不能由该 overlay 记录推出 HUDless 或 alpha。

## 本轮实机结论

run01 证明了：

- 实机 Native SR 可在目标场景运行。
- snapshot 可在指定真实帧记录并保留到 producer completion serial。
- capture archive、finalaccepted footer 与资源保护路径可以同时产生。
- 隔离运行没有修改原始 save/profile metadata 或原 settings 字节。

run01 没有证明：

- snapshot 已附着到实际 final resolve/present packet。
- `finalaccepted` 等于 producer-to-present lineage 成功。
- snapshot 是 HUDless color。
- alpha 已正确分解。
- provider 或 Reflex 已启用或消费该 packet。
- FG 已生成或显示。
- 全游戏、其他场景、无 SR、AA/TAA、resize、reset 或多帧在途兼容。

`UI=Unavailable` 仍是正确状态。不得根据场景 copy、minimap scissor、shader pair 或 draw count 做任意 UI 白名单或 alpha 推断。
