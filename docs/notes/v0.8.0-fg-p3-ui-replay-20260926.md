## run01 失败与修正

run01 executable SHA-256 为 `CC5D7C16C120BC9751E0A2E9A8CC49668539046A5562C08A626E3417B1DF1C35`。它在 `54.321` 记录 scene frame `3000`、source `6036`、source extent `2560x1472`、crop `2560x1440` 和 21 次 replay，在 `54.326` 因 `final_resolve_identity_or_format_mismatch` 被拒绝。
