# Reusable frame generation development

Baseline: `aaa04a67af63d6c93a4975223e5a4c6360e5ba14`.
Branch: `feature/reusable-fg-fsr-d3d12-mfg`.

## Maintainer acceptance

On 2026-09-27 the maintainer explicitly confirmed that the existing **FSR super resolution + DLSS Frame Generation** combination has passed acceptance. Preserve that accepted scope. This does not mean AMD FSR Frame Generation, D3D12 DLSS Frame Generation, or dynamic Multi Frame Generation were already implemented or accepted, and it does not claim another test run.

## Requested development

Implement independent AMD FSR Frame Generation, D3D12 DLSS Frame Generation, and dynamic MFG. Maximize reuse: separate frame generation from super resolution and game logic; share configuration, capability negotiation, frame/input ownership and presentation lifecycle. Keep provider-specific SDK calls in adapters. Never select both swapchain owners at once.

Implementation and validation results will be recorded here as they become available. The baseline experimental feature remains default-off. New API/platform support must be stated explicitly, not inferred from a common interface.
